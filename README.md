## Featured Projects

### Equipment Forge

A workflow automation tool originally developed in Java and JavaFX to streamline equipment documentation for a FedEx Express operation. The application automates asset tracking, barcode scanning, duplicate detection, and report generation, significantly reducing manual documentation time.

**Technologies:** Java, JavaFX, Git, HTML, CSS, JavaScript

---

### MPC (Metric Performance Calculator)

A Java-based analytics application that evaluates employee productivity using time-based performance calculations. MPC generates detailed reports and provides comparative metrics such as contribution percentages, percentile rankings, and customizable performance analysis.

**Technologies:** Java, JavaFX, Git

---

### Unity Link *(In Progress)*
